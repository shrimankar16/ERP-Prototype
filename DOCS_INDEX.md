## 🔄 Keeping Docs Updated

When you modify the platform:

1. **Add new feature?**
   - Update README.md → Features section
   - Update PROJECT_SUMMARY.md → Features list
   - Update PITCH.md if it affects demo flow

2. **Change deployment process?**
   - Update DEPLOYMENT.md
   - Test the new process completely

3. **New data or schools?**
   - Update README.md → Demo Data section
   - Update PITCH.md → Data integrity notes
   - Mark clearly if real vs illustrative

   - Update this DOCS_INDEX.md
